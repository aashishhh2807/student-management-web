# Student Management System

A simple **Student Management System** built using **Python, Flask, and MySQL** to understand how Python communicates with a SQL database through a web application.

## Overview

This project implements basic **CRUD operations** for managing student information.

- **Create** – Add a new student
- **Read** – View student details
- **Update** – Modify student information
- **Delete** – Remove a student

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- Jinja2
